# Mataram installer audit — 2026-10-29

## Changes applied

- Bootstrap now detects supported Debian/Ubuntu releases and amd64 architecture before installing dependencies.
- `setup.sh`, `install/run-install.sh`, `install/ssh-vpn.sh`, `install/xray.sh`, `install/set-br.sh`, and `domain/select-domain.sh` refresh APT indexes with retries and stop with a useful error if refresh/install fails.
- Removed the unattended full `apt upgrade` / `dist-upgrade` step from the SSH installer to avoid changing the VPS base OS during an application install.
- Xray is fetched at install time from the official XTLS/Xray-core latest Linux amd64 release, unpacked to a staging directory, validated with `xray version`, and atomically installed. This avoids overwriting a running executable and avoids a stale binary bundled in this repository.
- Removed the current-working-directory-dependent `rm -r xray.sh`; `run-install.sh` cleans `/root/xray.sh` after it exits successfully.
- Account scripts are copied from the downloaded source tree first; downloads are checked for HTTP errors and empty files and stop the installer instead of silently continuing.
- Recreated the zero-byte `accounts/user-ws.sh` file so the VMess WS account view is usable.
- Removed stray NUL bytes found in text shell scripts.
- Expanded `tools/check-shell-syntax.sh` to check shell syntax, empty `.sh` files, and NUL bytes.

## Validation performed

- `bash -n` was run against every `.sh` file in this source tree.
- `tools/check-shell-syntax.sh` was run after changes.
- ZIP integrity was checked with `unzip -t`.
- The live GitHub release download could not be exercised in the audit environment because DNS/network access from that environment was unavailable. The installer validates the downloaded archive and executable at runtime and fails clearly if the official release cannot be reached.

## Operational note

The installer requires working DNS/network access to Debian repositories, GitHub, and the selected domain's DNS. Retries improve transient failures but cannot fix a VPS that cannot resolve or reach those services. The installer still supports Debian 11/12/13 and Ubuntu 20.04/22.04/24.04/26.04 on amd64/x86_64, as declared by the project.
